# MVR_Assignment
Metaverse VR assignment for student placement

How to play
------------------------------
Keyboard:
WASD - Movement of boat
F3, Esc - Force Quit game

Gamepad:
Left Stick - Movement of boat
Start - Force Quit game

Aim of game
-----------------------------
Reach the green area adjacent to the dock in the quickest time possible.
You have a compass to guide you to where it is.
The faster you are, the higher the score & better rank you will recieve.
